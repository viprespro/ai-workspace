## 用户学习轨迹（重要背景）
- 用户具传统前端背景（React Router / Express 风格），正在理解本项目 Next.js 16 App Router + Vercel AI SDK 的约定式写法。
- 已逐步讲清并确认的链路：
  1. **文件即路由**：`app/chat/page.tsx` → `/chat`；`app/api/chat/route.ts` 的 `export async function POST(req: Request)` → `POST /api/chat`。无路由注册表。
  2. **Route Handler 用 Web 标准 API**：参数 `Request`（需 `await req.json()`），返回 `Response`/`NextResponse`，非 Express 的 `req/res`。
  3. **useChat 内部机制**：`useChat`（@ai-sdk/react）内部用 `useSyncExternalStore(subscribeToMessages, () => chatRef.current.messages)` 订阅 SDK 外部 store（`ReactChatState._messages`）。流式期间 `replaceMessage`/`pushMessage` 改 store 并通知 listener → 重渲染 ChatPage → messages 拿到新引用 → MessageList 重渲染（打字机效果）。**不是 React 的 setState 循环**。
  4. **transport 走到 /api/chat**：`DefaultChatTransport` 默认 `api="/api/chat"`，`sendMessages` 内 `fetch(POST)` 打该 URL；服务端 `toUIMessageStreamResponse()` 返回 SSE（UI Message Stream 协议 `text-delta`）。
